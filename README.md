# Lab 07 - Tic-Tac-Toe

## Ejercicio 3: Duelo IA-IA

Ejecuta el experimento desde consola con:

```bash
python main.py --duel
```

Opcionalmente puedes cambiar el tamaño del tablero y la cantidad de partidas:

```bash
python main.py --duel --size 4 --games 20
```

## Interpretación de resultados

- La IA más inteligente es la que gana más partidas.
- La IA más eficiente es la que tiene menor tiempo promedio por jugada.
- Si hay empate en victorias, el resumen indicará que no hubo una IA claramente más inteligente.
- Si el tiempo promedio es muy parecido, el resumen indicará que la diferencia es mínima.

El duelo alterna quién inicia en cada partida: en las impares inicia IA-1 y en las pares IA-2.
